## Alcance de esta entrega

Es una versión histórica para revisión académica. Las capturas y grabaciones son las recibidas; no se volvieron a ejecutar sus pruebas ni se certifican resultados a partir de las imágenes. No usar esta versión antigua como instalación clínica actual: seguir el Incremento 3 para instalar y evaluar el sistema vigente.

Se conservaron los ZIP originales localmente. La copia pública excluye contraseñas y respaldos con cuentas o registros privados. Las bases publicadas contienen estructura y, cuando venían incluidos, catálogos básicos; no contienen los usuarios ni tickets del respaldo. Consultar el control de recepción para los ajustes exactos.

GitHub guarda y distribuye los archivos; no deja este backend Node.js/MySQL funcionando en Internet.

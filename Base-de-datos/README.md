# Base de datos del incremento

Estructura histórica para consultar tablas y relaciones. Los registros privados se retiraron de la copia pública. Importar únicamente en una base de pruebas separada: algunos SQL recibidos incluyen DROP/CREATE y nombres de esquema. No ejecutarlos sobre mydb ni sobre una instalación existente.

Para instalar la versión vigente, usar https://github.com/BenjaGC/Incremento-3 y su guía técnica.
